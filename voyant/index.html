Read Your Own Essay from a Distance

Computers excel at pattern-recognition. Sometimes, these insights are mere noise; sometimes, they’re worthwhile signals.

Opening

Scholars use Voyant Tools to examine hundreds of books simultaneously. Today, we’ll point it at one class text, then you’ll aim it at your own draft.

Method

  1. Paste the class text into Voyant and note its five most frequent words.
  2. Read those words in context. Do they reveal anything that your first reading missed?
  3. Paste your own draft. Note your five most frequent words.
  4. Revise one paragraph based on what you see: a crutch word, a missing idea, a pattern worth keeping, etc.

For teachers

Voyant is a public website, so student drafts leave district systems when pasted in. If privacy’s a concern, we can install Voyant Server, a free version that runs offline, but would need to do so on an actual, non-Chromebook computer.
